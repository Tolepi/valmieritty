# 🟦 Valmieritty

**"Because circles are for people who can't handle the edge."**

Valmieritty is a terminal emulator born from a simple realization: the world has too many border-radius properties. It’s built in C, it’s faster than your current lifestyle, and it has more edges than a 14-year-old's Tumblr blog.

Its appearance looks similar to GNOME Terminal, but at this point i dont care, i am happy with this

## ⚠️ WARNING
Using this terminal might result in:
- A sudden urge to uninstall every "round" UI element.
- Increased elitism during Linux discussions.
- Extreme satisfaction when looking at 90-degree angles.
- An intense love for Terminess Nerd Font

## 🛠️ Requirements
If you don't have these, your computer is basically a glorified calculator:
- `libgtk-3-dev`
- `libvte-2.91-dev`
- A soul that appreciates industrial design.

## 🚀 Installation
If you can't type these 4 commands, you probably don't deserve these squares:

```bash
- git clone https://github.com/Tolepi/valmieritty
- cd valmieritty
- make
- sudo make install
```

🧠 FAQ

Q: Why are there no settings? A: Because the settings are perfect. If you want to change them, change the code and recompile it like a real adult.

Q: Can I have rounded corners? A: No. Go download a browser from 2012 if you want bubbles.

Q: Is this bloat-free? A: It's so light it's practically floating. It uses less RAM than a Chrome tab displaying a blank page.
